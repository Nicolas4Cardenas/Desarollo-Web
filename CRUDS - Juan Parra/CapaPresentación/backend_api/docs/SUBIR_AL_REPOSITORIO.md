# Incorporar al repositorio del equipo

La entrega nueva es la carpeta `backend_api`. Puedes colocarla en la raíz de
Nicolas4Cardenas/Desarollo-Web, junto a `backend_driver` y los ejercicios previos.
Es independiente: importa solo su propio paquete `poli`, no la carpeta anterior.

1. Haz copia de tus archivos y descarga/pull del estado actual del repositorio.
2. Copia `backend_api` desde el ZIP. No subas `.venv`, datos, config_mysql.json con contraseña
   ni entornos de Postman exportados con tokens o contraseñas reales.
3. Actualiza la referencia de la entrega en el README raíz para que apunte a backend_api.
4. Prueba los comandos y la colección con tu motor elegido.
5. Registra tus cambios con tu cuenta Git y sigue el flujo de rama/PR del equipo.

No necesitas borrar las carpetas históricas para ejecutar esta versión. No ejecutes sus
scripts SQL en la base actual. Las asignaciones de las HU no crean commits ni atribuyen
trabajo a otro integrante automáticamente.
