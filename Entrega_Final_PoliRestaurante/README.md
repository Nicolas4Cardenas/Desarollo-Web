# PoliRestaurante · Presentación completa

Abre primero [GUIA_PRESENTACION_COMPLETA.md](GUIA_PRESENTACION_COMPLETA.md).
Contiene la instalación en Windows, los permisos, cómo crear y recuperar cuentas
desde la página y un guion de sustentación.

- [CREDENCIALES_DEMO.txt](CREDENCIALES_DEMO.txt): accesos de clase y recuperación.
- `cliente_juan/`: interfaz HTML, Bootstrap y JavaScript para los tres roles.
- `backend_api/`: API Flask, driver MySQL/SQLite, SQL y colección de Postman.
- [DAO_FINAL.md](backend_api/docs/DAO_FINAL.md): inventario de los 13 DAO y cómo sustentarlos.
- `docs_juan/`: explicación de la operación de agregar productos.

Los reportes usan fechas y horas de Colombia.

Para entrar: arranca Flask con el motor de tu base y abre
[http://127.0.0.1:5000/](http://127.0.0.1:5000/).
