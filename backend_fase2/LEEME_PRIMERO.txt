POLIRESTAURANTE - FASE 2 BACKEND DRIVER

1. Descomprime este paquete en una carpeta con permiso de escritura.
2. Entra en backend_driver.
3. Ejecuta: python main.py (o py -3 main.py en Windows).
4. Crea tu primer administrador. No existen cuentas predeterminadas.
5. Inicia sesión; opciones 30,31,32,33 crean usuarios, categorías, productos y mesas.

Modo predeterminado: SQLite (driver incluido en Python). Sin pip ni MySQL.
Modo MySQL opcional: instrucciones en docs/MYSQL.md.
No ejecutes comandos Flask ni los SQL de la entrega web anterior.

Lee README.md para los pasos completos, datos guardados y menú de los tres roles.
Sustentación de Juan: docs/GUIA_SUSTENTACION_JUAN.md.
Pruebas: python -m unittest discover -s tests -v.
